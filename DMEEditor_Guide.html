Overview

The DMEEditor (Data Management Enterprise Editor) is the central orchestration engine for the entire platform. It acts as a comprehensive abstraction layer that coordinates data sources, manages connections, handles logging, and provides enterprise-level data management capabilities.

??? Enterprise Architecture

DMEEditor follows enterprise patterns including Dependency Injection, Factory Pattern, Repository Pattern, and Unit of Work. It serves as the main entry point for all data operations and maintains the application's data context.

Connection Lifecycle

Connection Creation Process

?? Connection Creation Flow

1. Configuration Lookup: Find connection properties in configuration

2. Driver Resolution: Link connection to appropriate driver configuration

3. Assembly Loading: Dynamically load the data source class

4. Instance Creation: Create data source instance using reflection

5. Configuration: Apply connection properties and driver settings

6. Registration: Add to DataSources collection for reuse

Factory Pattern for DataSources

Uses factory pattern with reflection for dynamic data source creation:

// Dynamic data source creation private IDataSource CreateDataSourceFromDefinition( ConnectionProperties connection, AssemblyClassDefinition classDefinition) { Type dataSourceType = assemblyHandler.GetType(classDefinition.type.AssemblyQualifiedName); ConstructorInfo constructor = FindBestConstructor(dataSourceType); var activator = GetActivator<IDataSource>(constructor); return activator(connection.ConnectionName, Logger, this, connection.DatabaseType, ErrorObject); }

Memory Management

Proper Disposal Pattern

protected virtual void Dispose(bool disposing) public void Dispose()

DMEEditor implements proper disposal patterns for resource cleanup:

// Safe disposal with error handling protected virtual void Dispose(bool disposing) { if (!disposedValue && disposing) { // Dispose DataSources safely foreach (var dataSource in DataSources) { try { if (dataSource?.ConnectionStatus == ConnectionState.Open) dataSource.Closeconnection(); dataSource?.Dispose(); } catch (Exception ex) { Logger?.WriteLog($"Error disposing data source: {ex.Message}"); } } // Clean up other resources DataSources.Clear(); ConfigEditor?.Dispose(); ETL?.Dispose(); } disposedValue = true; }

Connection Pooling and Reuse

Efficient connection management with caching:

// Connection caching and reuse private IDataSource ds1; // Cached data source public IDataSource GetDataSource(string dataSourceName) { // Check cache first if (ds1?.DatasourceName.Equals(dataSourceName, StringComparison.InvariantCultureIgnoreCase) == true) { return ds1; } // Look in collection ds1 = DataSources.FirstOrDefault(f => f.DatasourceName.Equals(dataSourceName, StringComparison.InvariantCultureIgnoreCase)); // Create if not found if (ds1 == null) { ds1 = CreateNewDataSourceConnection(dataSourceName); } return ds1; }

Usage Examples

Complete Application Setup

// 1. Initialize dependencies var logger = new DMLogger(); var util = new Util(); var errorObject = new ErrorsInfo(); var configEditor = new ConfigEditor(); var assemblyHandler = new AssemblyHandler(); // 2. Create DMEEditor var dmeEditor = new DMEEditor(logger, util, errorObject, configEditor, assemblyHandler); // 3. Load configuration configEditor.LoadConfigurations(); // 4. Set up progress reporting dmeEditor.progress = new Progress<PassedArgs>(args => { Console.WriteLine($"Progress: {args.Messege}"); }); // 5. Set up global event handling dmeEditor.PassEvent += (sender, args) => { if (args.IsError) { Console.WriteLine($"Global Error: {args.Messege}"); } };

Multi-DataSource Operations

// Work with multiple data sources simultaneously using (var dmeEditor = new DMEEditor(logger, util, errorObject, configEditor, assemblyHandler)) { // Open multiple connections var sqlServer = dmeEditor.GetDataSource("SqlServerDB"); var oracle = dmeEditor.GetDataSource("OracleDB"); var webApi = dmeEditor.GetDataSource("CustomerAPI"); // Perform ETL operation var customers = sqlServer.GetEntity("Customers", null); var processed = dmeEditor.ETL.TransformData(customers, transformRules); oracle.InsertEntity("ProcessedCustomers", processed); // Log the operation dmeEditor.AddLogMessage("ETL", "Customer data migrated", DateTime.Now, 0, $"Records: {((IList)customers).Count}", Errors.Ok); } // DMEEditor is automatically disposed

Entity Structure and Data Operations

// Get entity structure and work with data var customerEntity = dmeEditor.GetEntityStructure("Customers", "NorthwindDB"); // Add dynamic filters customerEntity.Filters = new List<AppFilter> { new AppFilter { FieldName = "Country", Operator = "=", FilterValue = "Germany" }, new AppFilter { FieldName = "City", Operator = "LIKE", FilterValue = "Berlin%" } }; // Get the data source and retrieve filtered data var northwind = dmeEditor.GetDataSource("NorthwindDB"); var germanCustomers = dmeEditor.GetData(northwind, customerEntity); // Use the utility functions to work with the data var dataTable = dmeEditor.Utilfunction.ToDataTable((IList)germanCustomers, typeof(Customer)); Console.WriteLine($"Found {dataTable.Rows.Count} German customers");

Local Database Creation

// Create a local database dynamically var localConnection = new ConnectionProperties { ConnectionName = "LocalTestDB", ConnectionString = "Data Source=test.db", DatabaseType = DataSourceType.Sqlite, IsInMemory = false }; // Create local data source var localDb = dmeEditor.CreateLocalDataSourceConnection( localConnection, "LocalTestDB", "SQLiteDataSource" ); if (localDb != null) { // Create tables, insert data, etc. var entities = localDb.GetEntitesList(); dmeEditor.AddLogMessage($"Local database created with {entities.Count} entities"); }

Async Operations with Progress

// Set up progress reporting for long operations dmeEditor.progress = new Progress<PassedArgs>(progress => { Console.WriteLine($"[{DateTime.Now:HH:mm:ss}] {progress.Messege}"); if (progress.ParameterInt1 > 0) { Console.WriteLine($"Progress: {progress.ParameterInt1}%"); } }); // Perform async operations try { var connectionState = await dmeEditor.OpenDataSourceAsync("LargeDatabase"); if (connectionState == ConnectionState.Open) { var dataSource = await dmeEditor.CreateNewDataSourceConnectionAsync("BackupDB"); // Perform data migration with progress reporting await dmeEditor.ETL.MigrateDataAsync("LargeDatabase", "BackupDB", new List<string> { "Customers", "Orders", "Products" }); } } catch (Exception ex) { dmeEditor.AddLogMessage("Error", ex.Message, DateTime.Now, 0, null, Errors.Failed); }
?? Best Practice: Always use DMEEditor within a using statement or manually dispose it to ensure proper cleanup of all data source connections and resources.
?? Thread Safety: While DMEEditor manages collections safely, individual data source operations should be coordinated when accessed from multiple threads simultaneously.

  • Lazy Loading: Components and drivers are loaded on-demand

  • Resource Pooling: Efficient management of database connections
  • Memory Management: Proper disposal patterns prevent memory leaks
