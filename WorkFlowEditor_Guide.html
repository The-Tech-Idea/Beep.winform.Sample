Overview

The WorkFlowEditor is a comprehensive business process automation engine that orchestrates complex data workflows and ETL operations. It provides a framework for defining, executing, and managing multi-step processes with advanced features like progress reporting, cancellation support, and rule-based execution.

?? Workflow Orchestration

WorkFlowEditor manages the execution of complex business processes by coordinating multiple actions, validating rules, and ensuring proper sequencing of operations. It supports both simple linear workflows and complex branching scenarios with conditional logic.

// Example custom action implementation [Addin(Caption = "Custom Process", Name = "CustomProcessAction", addinType = AddinType.Class)] public class CustomProcessAction : IWorkFlowAction { public CustomProcessAction(IDMEEditor dmeEditor) { DMEEditor = dmeEditor; Id = Guid.NewGuid().ToString(); NextAction = new List<IWorkFlowAction>(); InParameters = new List<IPassedArgs>(); OutParameters = new List<IPassedArgs>(); Rules = new List<IWorkFlowRule>(); } public PassedArgs PerformAction(IProgress<PassedArgs> progress, CancellationToken token) { var args = new PassedArgs { Messege = "Custom action started" }; try { WorkFlowActionStarted?.Invoke(this, new WorkFlowEventArgs { Message = "Custom action started", ActionName = Name }); IsRunning = true; // Custom action logic here progress?.Report(new PassedArgs { Messege = "Processing custom logic..." }); // Simulate work Thread.Sleep(1000); args.Flag = Errors.Ok; args.Messege = "Custom action completed successfully"; } catch (Exception ex) { args.Flag = Errors.Failed; args.Messege = $"Custom action failed: {ex.Message}"; } finally { IsRunning = false; WorkFlowActionEnded?.Invoke(this, new WorkFlowEventArgs { Message = args.Messege, ActionName = Name }); } return args; } }

Error Handling

Comprehensive Error Management

// Error handling is built into every operation try { var result = workflowEditor.RunWorkFlow("ProcessingWorkflow", progress, token); if (result.Flag == Errors.Failed) { Console.WriteLine($"Workflow failed: {result.Message}"); // Check workflow logs for detailed error information var errorLogs = workflowEditor.DMEEditor.ConfigEditor.Config.Logs .Where(log => log.Flag == Errors.Failed) .ToList(); foreach (var log in errorLogs) { Console.WriteLine($"Error: {log.Messege}"); } } } catch (OperationCanceledException) { Console.WriteLine("Workflow was cancelled by user"); } catch (Exception ex) { Console.WriteLine($"Unexpected error: {ex.Message}"); }

Cancellation & Control

Graceful Cancellation

// Cancellation is checked at multiple points during execution foreach (var step in workflow.Datasteps) { if (_cancellationTokenSource.Token.IsCancellationRequested) { DMEEditor.AddLogMessage("Workflow execution canceled."); return CreateErrorResult("Workflow execution canceled."); } progress?.Report(new PassedArgs { Messege = $"Executing step '{step.Name}'" }); foreach (var action in step.Actions) { // Pass cancellation token to each action var result = action.PerformAction(progress, _cancellationTokenSource.Token); if (result.Flag == Errors.Failed) { // Handle action failure break; } } }

Workflow Control Methods

// Start a workflow var workflowTask = Task.Run(() => { var result = workflowEditor.RunWorkFlow("LongRunningProcess", progress, cancellationToken); return result; }); // Stop the workflow if needed if (userRequestsStop) { var stopResult = workflowEditor.StopWorkFlow(); if (stopResult.Flag == Errors.Ok) { Console.WriteLine("Workflow stopped successfully"); } } // Wait for completion or cancellation try { var result = await workflowTask; Console.WriteLine($"Workflow result: {result.Flag}"); } catch (OperationCanceledException) { Console.WriteLine("Workflow was cancelled"); }

Usage Examples

Basic Workflow Creation and Execution

// Initialize WorkFlowEditor var workflowEditor = new WorkFlowEditor(dmeEditor); // Create a simple workflow var workflow = new WorkFlow { DataWorkFlowName = "CustomerDataProcessing", Description = "Process customer data from CRM to warehouse", Datasteps = new List<IWorkFlowStep> { new WorkFlowStep { Name = "DataExtraction", Actions = new List<IWorkFlowAction> { new ExportDataToFileAction(dmeEditor), new CleanseDataAction(dmeEditor) } }, new WorkFlowStep { Name = "DataTransformation", Actions = new List<IWorkFlowAction> { new DataTransformAction(dmeEditor), new DataValidationAction(dmeEditor) } } } }; // Add workflow to editor workflowEditor.WorkFlows.Add(workflow); // Execute the workflow var progress = new Progress<PassedArgs>(args => { Console.WriteLine($"Progress: {args.Messege}"); }); var result = workflowEditor.RunWorkFlow( "CustomerDataProcessing", progress, CancellationToken.None ); if (result.Flag == Errors.Ok) { Console.WriteLine("Workflow completed successfully"); }
