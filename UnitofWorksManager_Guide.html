Overview

The UnitofWorksManager class is a comprehensive data management system that simulates an Oracle Forms environment for .NET applications. It provides a higher-level abstraction for managing data blocks, master-detail relationships, triggers, and form-level operations.

?? Oracle Forms Equivalent

This class replicates the functionality of Oracle Forms' block management system, including triggers like WHEN-NEW-FORM-INSTANCE, PRE-INSERT, POST-QUERY, and form navigation operations like COMMIT_FORM and ROLLBACK_FORM.

public class UnitofWorksManager : IDisposable

TheTechIdea.Beep.Editor

Dependencies

  • IDMEEditor - Core data management editor interface
  • IUnitofWork - Unit of work pattern implementation
  • IEntityStructure - Entity metadata structure

Key Features

  • Block Management: Register and manage multiple data blocks with different entity types
  • Master-Detail Relationships: Automatic synchronization between related data blocks
  • Oracle Forms Triggers: Comprehensive event system mimicking Oracle Forms triggers
  • Navigation Control: First, Next, Previous, Last record navigation with dirty checking
  • Transaction Management: Form-level commit and rollback operations
  • Dirty State Tracking: Automatic tracking of unsaved changes with user prompts
  • Validation Framework: Field, record, and form-level validation support
  • Thread-Safe Operations: Uses ConcurrentDictionary for thread-safe block management

public void RegisterBlock(string blockName, IUnitofWork unitOfWork, IEntityStructure entityStructure, string dataSourceName = null, bool isMasterBlock = false)

Registers a data block with the manager. This is equivalent to creating a data block in Oracle Forms.

// Example: Register a customer block var customerUow = new UnitofWork<Customer>(dmeEditor); var customerEntity = dmeEditor.GetEntityStructure("Customers"); manager.RegisterBlock("CUSTOMERS", customerUow, customerEntity, "NorthwindDB", true);

Form-Level Operations

OpenFormAsync

public async Task<bool> OpenFormAsync(string formName)

Opens a form and triggers the OnFormOpen event. Equivalent to Oracle Forms WHEN-NEW-FORM-INSTANCE.

CloseFormAsync

public async Task<bool> CloseFormAsync()

Closes the form after checking for unsaved changes. Triggers appropriate events and cleanup.

CommitFormAsync

public async Task<IErrorsInfo> CommitFormAsync()

Commits all changes in all blocks. Equivalent to Oracle Forms COMMIT_FORM.

// Example: Commit all changes var result = await manager.CommitFormAsync(); if (result.Flag == Errors.Ok) { Console.WriteLine("All changes committed successfully"); } else { Console.WriteLine($"Commit failed: {result.Message}"); }

RollbackFormAsync

public async Task<IErrorsInfo> RollbackFormAsync()

Rolls back all changes in all blocks. Equivalent to Oracle Forms ROLLBACK_FORM.

ClearAllBlocksAsync / ClearBlockAsync

public async Task ClearAllBlocksAsync() public async Task ClearBlockAsync(string blockName)

Clears all blocks or a specific block. Equivalent to Oracle Forms CLEAR_FORM and CLEAR_BLOCK.

?? Warning: Form operations are transaction-aware and will check for unsaved changes before proceeding.

Dirty State Management

The UnitofWorksManager provides sophisticated dirty state tracking and user interaction:

Checks for unsaved changes in a block and its children, prompts user for action.

OnUnsavedChanges Event

public event EventHandler<UnsavedChangesEventArgs> OnUnsavedChanges;

Event raised when unsaved changes are detected. Allows user to choose action:

manager.OnUnsavedChanges += (sender, e) => { var result = MessageBox.Show( $"You have unsaved changes in {e.DirtyBlocks.Count} blocks. What would you like to do?", "Unsaved Changes", MessageBoxButtons.YesNoCancel); switch (result) { case DialogResult.Yes: e.UserChoice = UnsavedChangesAction.Save; break; case DialogResult.No: e.UserChoice = UnsavedChangesAction.Discard; break; default: e.UserChoice = UnsavedChangesAction.Cancel; break; } };

Usage Examples

Complete Customer-Orders Form Example

// Initialize the manager var manager = new UnitofWorksManager(dmeEditor); // Register customer block (master) var customerUow = new UnitofWork<Customer>(dmeEditor); var customerEntity = dmeEditor.GetEntityStructure("Customers"); manager.RegisterBlock("CUSTOMERS", customerUow, customerEntity, "NorthwindDB", true); // Register orders block (detail) var ordersUow = new UnitofWork<Order>(dmeEditor); var ordersEntity = dmeEditor.GetEntityStructure("Orders"); manager.RegisterBlock("ORDERS", ordersUow, ordersEntity, "NorthwindDB", false); // Create master-detail relationship manager.CreateMasterDetailRelation("CUSTOMERS", "ORDERS", "CustomerID", "CustomerID"); // Set up event handlers manager.OnPreInsert += (sender, e) => { if (e.BlockName == "CUSTOMERS") { // Set audit fields for new customers e.SetCurrentDateTime("CreatedDate"); e.SetCurrentUser("CreatedBy", "CurrentUser"); } }; manager.OnUnsavedChanges += (sender, e) => { // Handle unsaved changes with user prompt var result = MessageBox.Show("Save changes?", "Confirm", MessageBoxButtons.YesNoCancel); e.UserChoice = result == DialogResult.Yes ? UnsavedChangesAction.Save : result == DialogResult.No ? UnsavedChangesAction.Discard : UnsavedChangesAction.Cancel; }; // Open the form await manager.OpenFormAsync("CustomerOrdersForm"); // Execute initial query await manager.ExecuteQueryAsync("CUSTOMERS"); // Navigate through records (orders will sync automatically) await manager.NextRecordAsync("CUSTOMERS"); await manager.PreviousRecordAsync("CUSTOMERS"); // Commit all changes var commitResult = await manager.CommitFormAsync();

Custom Validation Example

// Field-level validation manager.OnValidateField += (sender, e) => { switch (e.FieldName.ToLower()) { case "email": if (!IsValidEmail(e.Value?.ToString())) { e.IsValid = false; e.ValidationMessage = "Invalid email format"; } break; case "phone": if (!IsValidPhone(e.Value?.ToString())) { e.IsValid = false; e.ValidationMessage = "Invalid phone number"; } break; } }; // Record-level validation manager.OnValidateRecord += (sender, e) => { if (e.BlockName == "CUSTOMERS") { // Ensure required fields are filled var customerName = manager.GetFieldValue(currentRecord, "CustomerName"); if (string.IsNullOrEmpty(customerName?.ToString())) { e.IsValid = false; e.ValidationMessage = "Customer name is required"; } } };
?? Best Practice: Always handle the OnUnsavedChanges event to provide a good user experience when navigating away from dirty data.

Thread Safety

The UnitofWorksManager uses ConcurrentDictionary for thread-safe operations on block collections. However, individual block operations should still be coordinated at the application level if accessed from multiple threads.

Memory Management

The class implements IDisposable and properly cleans up event subscriptions and resources. Always dispose of the manager when done:

using (var manager = new UnitofWorksManager(dmeEditor)) { // Use the manager } // Automatically disposed
